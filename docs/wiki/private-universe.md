## 一句话定义

**PU-12** 是用仓库里**已经证明过的**三件数学搭起来的宇宙模型：

```
频率阶梯   振动坐标系（Vibration.lean / VibrationGeometry.lean）  振数 → 频率 → 能量
结构      隐数（HIBS S/R/iR 三射线）× 隐数空间三维（σ₁σ₂σ₃）      每维 3 子 × 3 亚 = 9 格
流动      张力计数法（TensionReading.collapse）                    τ = 条数差 ⟹ 能量流向
```

12 个频率带（对数量级均分，天花板 `10^41 Hz`）、12 个维度、每维 3 子维度与 3 亚维度、
初始能量授予、后续能量从相邻结构维度内生获得 —— 这些是**给定参数**；
本页与其配套 Lean / Python 交付的是**它们逼出的东西**：带宽 `10^5`、地板 `10^-19 Hz`、
纯度单调性、能量流守恒、平衡判据、阶梯封闭。

配套：
`Nods/Theories/Universe.lean`（Lean，0 sorry）、

## 2. 频率阶梯：5 个数量级一带，地板 `10^-19`

阶梯：`bandHi k = 10^41 / 10^(5k)`，`bandLo k = bandHi (k+1)`（首尾相接）。

**为什么是 5 个数量级，不是 4 或 6。** 三个条件同时用：

1. 12 带均分（对数量级切分）⟹ 带宽 `= 10^m`，地板 `= 10^(41-12m)`；
2. 地板必须 ≤ 宇宙视界频率 `f_H = 1/T_U = 2.30×10^-18 Hz`
   （否则存在物理上已有、却无法寻址的模）；
3. 带宽取整数个数量级（decade-aligned，否则带沿不落在数量级上）。

`41 - 12m ≤ log10 f_H = -17.64 ⟹ m ≥ 4.89`，整数里**最小**的是 `m = 5`：

| m | 地板 | 覆盖视界？ |
|---|---|---|
| 4 | `10^-7 Hz` | ✗ 差 11 个数量级 |
| **5** | **`10^-19 Hz`** | **✓ 刚好低 1.06 个数量级** |
| 6 | `10^-31 Hz` | ✓ 但 13 个数量级是「潜伏带」（周期远超宇宙年龄）|

后果（Lean 已证）：相邻带能量比恒为 `r = 10^5`（`band_ratio`）；
`bandLo 11 = 1/10^19`（`bandLo_eleven`）；低于地板不属于任何带（`no_band_below_floor`）、
高于 `10^41` 也不属于任何带（`no_band_above_ceiling`）—— **阶梯是封闭的，不是截断的**。

## 3. 子维度 = 隐数空间三维，亚维度 = 隐数三射线

用户的口径：**隐数是子维度和亚维度的数学**。落到数学上分两层：

- **3 个子维度** = 隐数空间的三根轴 `σ₁ σ₂ σ₃`（Pauli 三轴；HIBS 的球谐实现里
  `(σ₁+σ₂+σ₃)² = 3I`，三轴等距，这正是「三维」的代数来源）。
- **3 个亚维度** = 一个隐数能待的三条射线 `S / R / iR`
  （HIBS 三公理：A1 投影有损、A2 `×÷` 强制投影到 R、A3 `√` 强制投影到 iR）。

``` 
维度 k  ⊃  子维度 s = 1,2,3 (σ₁σ₂σ₃)  ⊃  亚维度 r = S, R, iR
        ⟹ 9 个隐数格 (s, r)，条数 size ∈ [0, 9]
```

**条数**：一个维度的 `size` = 已被点亮的隐数格数。这就是 TCM 的「一条一条数」，
也是张力唯一的输入 —— 与能量大小无关。

**纯度与射线（公理 A5）**：高带的相位要闭合，需要更深的开方塔
（`Radical.lean`：幂 = 按 `μₙ` 折叠的商，开方 = 把覆盖撑开的截面），
所以带越高，越多的格落在 `iR` 射线。射线层级取 `S = 1/3, R = 2/3, iR = 1`，
9 格平均即**隐数纯度**，随带升高而不增（9 格分辨率低于 12 带，故有平局 —— 这是分辨率上限，不是缺陷）。

## 4. 流动律：张力计数法给出的不是方程，是「只看得见条数」

TCM 的塌缩定理（`AtomicReading.collapse`）说：**共享项必须约掉，张力只能是条数差**。
`Universe.lean` 把它实例化成一个具体的 `AddTension`（`countTension`：K = a 侧独有、L = b 侧独有），
于是

```
τ(i,j) = size i − size j        （countTension_collapse，直接调用仓库已证定理）
```

**这就是能量流动定律的全部输入**。三个直接后果：

1. **方向**：能量从条数多的维度流向条数少的（新生维度条数 0、父维度 9 ⟹ `τ = 9`）。
2. **停止**：`τ = 0 ⟺ 条数相等`（`tension_zero_iff`）。宇宙的平衡是**结构的**，不是热学的 ——
   条数一齐，能量再悬殊也不流（TCM「内容不可见」的宇宙版）。
3. **量级**：τ 是**力**的大小，不是能量；每单位张力搬多少量子由耦合 `κ` 决定（见 §6 消融）。

## 5. 能量与纯度：三条定义，同一排序

| 定义 | 形式 | 含义 |
|---|---|---|
| 谱纯度 | `π = log10(f/f_floor)/60` | 在阶梯上的位置 |
| 量子纯度 | `π = ε/E = 1/n` | 定量能量装进更重的量子 ⟹ 量子数更少 ⟹ 更纯 |
| 隐数纯度 | 9 格射线层级均值 | 相位展开的深度 |

三者都不出现反序（Python 逐带核对），Lean 里前两条是定理：
`spectralPurity_strictAnti`、`quantumPurity_lt_of_lt`（同一份能量，ε 越大越纯）、
`purity_agree`（两版一致）。**「频率越高能量越纯粹」因此不是设定，是被两条独立定义同时满足的性质。**

能量本身：`ε_k = ℏω_k`（`quantumE`），`ω_k = 2πf_k`（振动坐标的连续读法：
`step_phase_advance` 说一步推进 `1/period` 圈 ⟹ 角速度 ∝ 频率）。
`ε_k / ε_{k+1} = 10^5`（`quantumE_ratio`）—— 与 `band_ratio` 同源，正是跨带交换能精确守恒的原因。

物理标定（只做量纲换算，不参与动力学）：`ε₀ = ℏ·2π·10^38.5 ≈ 2.10×10^5 J ≈ 1.31×10^24 eV`；
最高带上沿一个量子 `= 6.63×10^7 J = 4.14×10^26 eV`；最低带上沿 `= 6.63×10^-53 J`。

## 6. 动力学：维度扩展是能量逐级转写

初始授予：`E₀ = 9 ε₀` —— **恰好每个隐数格一个量子**，第一维的 9 格同时点亮。
之后每一代：

```
q = τ(parent, newborn) = 9 − 0 = 9        （条数差，Lean: countTension_collapse）
1 个量子跨一带  ⟹  10^5 个量子             （ε_k = 10^5 · ε_{k+1}，能量精确相等）
新维度出生即带整副 3×3 格（原子出生）⟹ 与父维度 τ = 0 ⟹ 不再回流
```

于是出现一条**精确闭式**的宇宙史（Fraction 精确算术，无浮点）：

| 代 | 维度数 | 总量子数 N | 总能量 / ε₀ | 平均量子能量 Π = E/N = 9/N |
|---|---|---|---|---|
| 0 | 1 | 9 | 9 | 1 |
| 1 | 2 | 9×10^5 | 9 | 10^-5 |
| 2 | 3 | 9×10^10 | 9 | 10^-10 |
| … | … | … | 9 | … |
| 11 | 12 | 9×10^55 | 9 | 10^-55 |

结构后果（全部机器核对，30/30）：

- **能量精确守恒** `E = 9ε₀` 每一步（`energy_exch` 的连续版）；
- **量子数每代精确 ×10^5**，平均量子能量（纯度）每代精确 ×10^-5；
- **内生获得**：每一维出生时从上一结构维度获得整整 `9 ε₀`（整份能量的一次转写，不衰减）；
- **终止**：走到第 12 维后无带可生（地板以下没有带）⟹ 宇宙史有限，共 11 代。

**消融（同代码可复跑）**：

| 配置 | 结果 | 说明 |
|---|---|---|
| 张力门控（κ = 1，每代搬 τ = 9 个量子） | 仍长满 12 维，N = 9.9×10^6 | τ 同时定量级时，上部各带留住能量 |
| 单位流量（每代 1 个量子） | 仍长满 12 维 | 级联不依赖搬多少，只依赖 τ > 0 |
| 非原子出生（1 格，τ 塌到 1） | 仍长满 12 维，第二级只搬 1 个量子 | 条数决定节奏 |
| 反向·全量（向高频精炼） | 12 维，纯度 10^-55 → 1 | 镜像过程：量子数每级除以 10^5 |
| 反向·张力门控 | **停在 2 维** | τ ≤ 9 ≪ r = 10^5 ⟹ 凑不出一次「10^5 合 1」，级联卡死 |

最后一行是模型的一个真结论：**阶梯在「冷却」方向走得通、在「精炼」方向被量子整数性卡住**
（除非耦合 κ 大到能一次搬 10^5 个量子）。这是 `r = 10^5` 与 `条数 ≤ 9` 的直接冲突，
不是调参问题。

连续版与 Lean 版的三处**显式差别**（都写在代码注释里）：

1. **成熟时间 `--mature`**：满格后要持续 `mature` 拍才允许生下一维 —— 把「维度出生」摊到可观察的
   时间尺度上（`mature=3000` 时一轮宇宙史 ≈ 3.3×10^4 拍）。
2. **耦合 κ**：每代把 `κ∈[0.2,0.8]` 比例的束交给下一维（Lean 版是整份转写）；κ 异质 ⟹ 系综里
   各宇宙发展速度不同，才有分布可看。
3. **相位层**：每带 64 个振子按 `θ += 2π f_k dt` 演化（带 0 转最快），带内频率有离散 ⟹ 走离相；
   通量到达时弱锁相。序参量 `R` 就是「相位纯度」的第三种读法。

提案网（12→64→3→12，3 维 = 隐数空间三维）只**猜**下一维长在哪，规则负责接受；
接受率是学习曲线，不参与物理。束数守恒在 float64 下日志里记 `energy_err`（实测 < 2×10^-15）。

## 9. 诚实边界

- **不给物理预言**。模型给的是结构（阶梯、条数、流通、平衡、封闭）与精确守恒记账，
  不是对真实辐射、膨胀或量子引力的模拟。
- **`10^41 Hz`、12 带、3×3 结构、初始能量是给定参数**；「5 数量级 / 地板 `10^-19` / r = 10^5」
  是从「均匀分带 + 覆盖视界 + 整数 decade」逼出来的，属于本模型的推导结论。
- **A5（射线随带升高而偏 iR）是公理**，机制解释（相位闭合需要更深开方）是动机而非证明；
  Lean 证的是谱纯度与量子纯度的单调性，隐数纯度只做了逐带一致性核对。
- **耦合 κ 是自由参数**：κ = ∞（全量转写）与 κ = 1（τ 定量级）都自洽，两者的差别已在消融表里列出，
  不假装它是被逼出来的。
- 反向级联卡在第 2 维是 `r = 10^5` 与 `条数 ≤ 9` 的结构性冲突，若将来允许「合并需要更深的开方层」
  （Radical：开方是无次数上限的），这个卡点可以再讨论。
