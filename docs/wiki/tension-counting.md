## 一句话定义

**张力计数法（Tension Counting Method, TCM）** 是一套极简公理，用于直接刻画**两个数字自身之间**的收敛趋势与发散趋势——不经由任何你选定的公式、度量或函数，只由数对的内在算术 / 序结构决定。

它瞄准的是数学里一块未被观测的空间：**数字之间的「张力」作为第一性对象**，而非 `|a−b|` 这种标量距离的化名。

## 为什么它成立：数字层面的直读（最简单的逻辑）

### 三句话

1. **每个数就是一捆素数条。** 唯一分解定理把 `n` 拆成 `p₁^{a₁}···p_k^{a_k}`：
   不同的素数各算**一条**（`12 = 2²·3` 的条是 `{2, 3}`，两条 —— 重复的幂不生新条）。
   这不是我选的读法，是算术本身给好的。
2. **两条数并排，每条素数只有三种身份**：两边都有 / 只在 a / 只在 b。
   数对能被读出来的东西就这三样，所以张力也只能由这三样决定 ——
   这就是「T1 直接性」，它不是一条规定，是一句实话：**本来就只有这些可读。**
3. **力必须有方向，所以「两边都有」必须出局。** 共享的部分对 `a→b` 和 `b→a` 一模一样：
   对称、没有方向、推不动任何一边。它不可能是力（一个推不动东西的东西）。
   力只能来自**不对称**的那部分。

### 于是张力就是一句话

```
τ(a→b) = (只在 a 的条数) − (只在 b 的条数) = |S_a ∖ S_b| − |S_b ∖ S_a|
```

读法：**谁比谁多几条独有**。`τ > 0` 一边倒向 a，`τ < 0` 倒向 b，`τ = 0` 平衡。

两条性质不用证就有：反着读反号（差取反）；自己和自己为零（没有独有）。

> 关于「收敛力」：`K` 与 `L` 是把 τ 拆成两半的记账（T2）。公理 T5 规定
> **共享不许算进任何一边**，所以两半只能是那两条独有。
> 至于哪一半叫「收敛」、哪一半叫「发散」—— 那正是被证明**自由**的那个取向
> （两个解 `τ` 与 `−τ` 互为反着读）。被定下来的是「独有之差」，不是标签。

### 例：60 与 45

```
60 = 2² · 3 · 5   →  素数条 {2, 3, 5}
45 = 3² · 5       →  素数条 {3, 5}

共享      {3, 5}  →  2 条   （对称，推不动，不进张力）
只在 60   {2}     →  1 条
只在 45   {}      →  0 条

τ(60 → 45) = 1 − 0 = +1     张力指向 60
τ(45 → 60) = 0 − 1 = −1     反着读，反号
```

一句话读法：**45 的条 60 全有，60 还多一条 `2` —— 所以张力 `+1`（一边倒）。**

四个对照（全部机器核对：`ex_60_45` / `ex_45_60` / `ex_12_18` / `ex_2_3` / `ex_30_7`）：

| 数对 | 只在 a | 只在 b | τ(a→b) | 读法 |
|------|--------|--------|--------|------|
| 60, 45 | {2} | {} | **+1** | 一边倒：60 多一条 |
| 45, 60 | {} | {2} | **−1** | 反着读，反号 |
| 12, 18 | {} | {} | **0** | 支撑完全相同 → 平衡 |
| 2, 3 | {2} | {3} | **0** | 互素，但一样陌生 → 平衡 |
| 30, 7 | {2,3,5} | {7} | **+2** | 互素，但 30 多两条 → 一边倒 |

**最后两行的区别是这个方法的要害**：它量的不是「像不像」，是「谁比谁多」。
`2` 和 `3` 一点也不像（互素），但彼此一样陌生，张力为零；
`30` 和 `7` 同样互素，可 `30` 手里比 `7` 多两条，张力就出来了。

### 为什么这个能算

输入只有两个数，输出是一个整数：**分解一下，数三种条各多少，相减。**
有限、可判定、无公式、无极限、无参数。

这正是它和「公式的收敛 / 发散」的区别：后者要一个**过程**（级数、流），
前者只要**两个数**。数字自身的张力，第一次有了一个只需要两个数的算法。

## 动机与边界

- 现有数学已有公式的收敛 / 发散（级数、积分、动力系统），但那描述的是**过程**，对象是数。
- 收敛 / 发散永远属于某个过程（序列、流），从来不是两个裸数的性质。
- 因此真正的缺口**不是**「数没有张力」，而是：**不存在一个由数对「自身算术结构」强制决定的、用户无法自由选择的「内在流 / 内在力」，使得任意两数直接呈现收敛力或发散力，并带一个临界（零张力）流形。**
- 度量（metric）给你一个标量距离，但**不给临界流形**；TCM 要的 `T=0` 临界对，是度量没被迫给出的新对象。

> NODS 纪律提示：本页当前是 **candidate gap（候选缺口）**，**不是已证发现**。缺口证明 `O-TCM-gap` 是开放义务（见末节）。在证出之前，最多是「设计选择」。

## TCM-0：纯公理（领域无关）—— ⚠️ 初版，已被上面的权威表取代

> 保留于此只作**演进记录**。这里的 `T4 允许有向` / `T5 自临界` 是初版措辞，
> 已被权威表的 `T4′ 必须反号` / `T5 自零（两力皆零）` 取代；`T3` 拆成 `T3a`（冗余）+ `T3b`（保留）。

### 原始词项

- 一个数域 `D`
- 一个「张力结构」`G`（离散域取 `ℤ`，连续域取 `ℝ` 的某子结构）
- 对每个 `a,b ∈ D`，一个**不可再约**的张力对象 `τ(a,b)`，不是 `|a−b|` 的化名

### 公理（极简，5 条）

```
T1  直接性：τ(a,b) 只由 {a,b} 在 D 内的内在算术/序结构决定——
           不存在任何外部函数 f 作为参数。        ← 反度量公理
T2  二分力：τ 分解为「收敛力」K(a,b) 与「发散力」L(a,b)，
           不是单一幅度。  T_grade(a,b) := K − L ∈ G
T3  临界流形：crit(a,b) ⇔ T_grade(a,b) = 0，
            且 { (a,b) : crit } 是真非平凡子集（非全、非空）
T4  方向性（弱版）：允许 τ(a→b) ≠ τ(b→a)
           （度量必对称，这里不强制对称 → 是「力」而非「距离」）
T5  退化：T_grade(a,a) = 0 且 crit(a,a) 成立（自临界）
```

### NODS 缺口主张

若现有 `D` 上的结构（度量 / 序 / 半环 / 整除偏序）能在**同一载体**上**被迫**承载 T2+T3 → 是 `solved`（新颖性 0）。当前主张：没有任何现有 ℕ/ℤ/ℝ/ℂ 结构会强制出一个「带临界流形的、函数无关的、数对自身的二分力」。这是待证义务 `O-TCM-gap`。

## 实例化 1：ℕ（最干净，可真算）

用**素因子 radical** 作为「数自身的结构」：

```
令 S = rad(a) 的素因子集, T = rad(b) 的素因子集
K(a,b) = |S ∩ T|          共享素数 → 收敛力
L(a,b) = |S Δ T|          独有素数 → 发散力
T_grade(a,b) = K − L ∈ ℤ
crit(a,b) ⇔ K = L
```

算例：

| (a,b) | S | T | K | L | T | 判定 |
|-------|---|---|---|---|---|------|
| (8,12) | {2} | {2,3} | 1 | 1 | 0 | 临界对 |
| (12,18) | {2,3} | {2,3} | 2 | 0 | +2 | 强收敛 |
| (2,5) | {2} | {5} | 0 | 2 | −2 | 强发散 |
| (6,10) | {2,3} | {2,5} | 1 | 2 | −1 | 偏发散 |

> ⚠️ **上表违反公理 T5**（机器检查，见下节 §Lean 形式化）：取 `a = b` 时
> `T_grade = |S∩T| − |SΔT| = |S| = ω(a) ≠ 0`，自临界不成立。表中算例全取 `a ≠ b`，
> 故此前未暴露。这不是排版问题——公理与实例至少有一个要改（两条出路见下节）。

**临界流形** = 「共享素数数 = 独有素数数」的数对集合 —— 这是 ℕ² 上一个全新、可观测的等价-类结构，度量给不出。

**方向性扩展（满足 T4）**：`τ(a→b) = K + [S⊆T] − L`（`[S⊆T]` 指 b 吸收 a 的全部素因子时 +1）。
则 `(6→12)` 得 +1 而 `(12→6)` 得 0 → 方向性出现，正是「收敛力 / 发散力」作为力的体现。

## 实例化 2：ℤ（带符号扩展）

在 ℕ-radical 张力上追加符号项：

```
τ_ℤ(a,b) = τ_ℕ(rad|a|, rad|b|) + signTerm(a,b)
signTerm = +1  若 ab > 0      （同号 → 收敛）
         = −1  若 ab < 0      （异号 → 发散）
         = +1  若 0 ∈ {a,b}   （0 是「万有吸引子」）
```

`0` 成为一切张力的收敛汇点 —— 给「数字自身的吸引 / 排斥」一个极简载体。

## 实例化 3：ℝ（用连分数，不用量度）

实数无素数，改用**连分数展开**这种「实数自身的内在结构」（非选定度量）：

```
写出 a,b 的连分数 [a0;a1,a2,…], [b0;b1,b2,…]
K(a,b) = 共享初始部分商块数          （可公度性 → 收敛）
L(a,b) = 首个分歧部分商的大小（封顶）  （不可通约性 → 发散）
T_grade(a,b) = K − L_term ∈ ℤ
```

`K` 大 = 两数在连分数意义下「同源」（如 `√2` 与 `1+√2` 共享周期块）→ 收敛；首个分歧商巨大 = 结构性背离 → 发散。临界流形 = 同源度与背离度平衡的对。

## 实例化 4：ℂ（对标黎曼临界线）

把「临界线」直接变成张力场的**最大收敛轨迹**：

```
临界贴近度  c(z) := 1/2 − |Re z − 1/2|      （越靠 Re=1/2 越大，封顶 1/2）
T(z,w)    := (c(z) + c(w)) − sep(z,w)
其中 sep 是 z,w 间的归一化互分离
crit(z,w) ⇔ T = 0
```

于是 **Re=1/2 临界线 = 张力场的「最大收敛轨迹」**，零点配对若落在临界流形上就被张力计数法「自然」挑出。
⚠️ 草案：`sep` 的选取仍需定死，否则会退化成「伪装成张力的度量」（NODS 黑名单第 1 条：把换载体当已解）。

## 缺口分析（O-TCM-gap，ℕ 结果：solved，非 gap）

按 NODS 三分判定对 ℕ 实例化做 `HasSolution` 检查：

**世界 S** = (ℕ, {0,1,+,·,≤}) 标准一阶算术结构。**需求 D** = 存在 T: ℕ×ℕ→ℤ 满足 TCM-0（T1–T5），按素因子 radical 实例化。

**可定义性链**：素数在 (ℕ,+,·) 中一阶可定义（`Prime(p) ↔ p>1 ∧ ∀x,y. x·y=p → x=1∨y=1`）；整除 `d|a ↔ ∃k. d·k=a` 可定义；故 `rad(a)`、素因子集 S/T、K、L、T=K−L 全部在 S 内一阶可定义。

**结论**：T(a,b) 在现有结构 S 的**同一载体**上即可承载 → **`solved`，不是 `gap`**。在「存在性」层面新颖性 = 0。

**NODS 黑名单自检**：
- 这不是缺口，是可满足需求 → 不得宣称发现。

- 因此 TCM-0 在 ℕ 上是**设计选择 / 记号**，不是被迫对象（「我选了一个记号」）。

**真正的开放问题（canonicity，非 existence）**：存在性不是问题，**唯一性 / 强制性**才是。真正缺口候选在 ℂ：要求 T(z,w) 由 ζ 结构强制、且 Re=1/2 是唯一最大收敛轨迹。裸 ℂ 的域/拓扑结构**不**强制此性质（临界线可任意放、或没有），唯 ζ 函数强制之。此即 `O-TCM-canon`（开放）。只有这里，TCM 才可能从「记号」升级为「发现」。

## TCM-1：加判别公理，把 τ **逼出来**（核心结果）

TCM-0 之所以只是「记号」，是因为公理组**不唯一确定** τ（见上节 `crit_manifold_not_unique`）。
出路不是再加实例，而是加**判别公理** —— 把「张力计数法」的计数语义本身写成公理。
`Nods/Theories/Tension.lean` §5–6 已把下面这套落成 0 sorry / 0 warning 的机器检查：

| 公理 | 内容 | 为什么少不了 |
|------|------|-------------|
| **T6 计数** | 两个力都是**剖面** `(共享, a独有, b独有)` 的**可加**函数 —— 每多一条素数就多固定的一份力，与其它条无关 | 这就是「元计数」本身：数条数、不加权 |
| **T7 单位** | 每个素数对每个力**至多贡献一条**（系数 ∈ {0,1}） | 「条」不可再分；去掉它系数可以任意大 |
| **T4′ 反号** | **把数对反着读，张力严格反号**：`τ(b,a) = −τ(a,b)` | 关键一条：T4 只「允许」有向，升级为「必须反号」才逼得住 |
| T5 自零 | 数和自身两力皆零（对角剖面 `(t,0,0)`） | 把「共享条」从两个力里同时清零；否则 `(K,L)` 对不唯一（见 `T5_needed`） |

**主定理（`forced_unique`）**：满足 T5 + T7 + T4′ + T3b 的几何计数张力，其张力差只能是

```
τ(a,b) = |S∖T| − |T∖S|        或        它的反号
```

**没有第三种可能。** 两个解互为「把数对反过来读」—— 正是 T4′ 的取向，故 τ 唯一到取向。
并且 `forcedTension_to_dirTension` 证明它读回数对后**正是上一节的 `dirTension`** ——
被逼出来的对象，就是我们手里那个。

### 三条最小化结论（HIBS 第 7/8 步）

1. **T3a（临界非平凡）是冗余的**：`nontrivialCrit_free` 证它在 T5+T7+T4′+T3b 下自动成立 —— 能推的别列。
2. **T5 不可省**：`T5_needed` 造出另一个 `(K, L)` 对，张力差完全相同但 `K` 不同 —— 要逼出**一对力**，T5 必需。
3. **T4 必须升级为 T4′**：原文「允许有向」逼不出唯一性，只有「必须反号」才逼得住。这是 TCM-0 → TCM-1 的**关键改动**。

### 与 R→C 同型

`(ℕ, K = |S∖T|)` 与 `(ℕ, K = |T∖S|)` 是同一载体的两个极小扩张，两者唯一同构
（那个同构就是「反着读」= 取反号）。这正是本仓库 R→C 的 `(C, i)` / `(C, −i)` 模式：
**最小 + 刚性**。所以 TCM-1 下的张力计数法，不再是一个记号，而是一个**被迫对象**。

## 最小化审计：每条公理究竟在干什么（§7–8）

再压一轮后，公理表变成「**一条管形状、一条管单位**」，其余全部可推，或可换更自然的写法。

### 1. 分工定理 —— T6 与 T7 不能合并（它们管的事正交）

| 定理 | 内容 |
|------|------|
| `form_up_to_scale` | T5 + T4′ + T3b ⟹ 张力只能是 `c · (\|S∖T\| − \|T∖S\|)`，`c ≠ 0` —— **形状被完全逼出，只留一个整数单位** |
| `unit_fixes_scale` | 再加 T7，那个自由单位被钉成 `±1` —— **T7 唯一的工作就是定单位** |

⇒「T6 与 T7 能否合并」的答案是**不能**：T6（可加）管形状，T7（单位）管刻度，两件事。

### 2. 单位表可换成一条「计数界」

`Unit`（四条点态约束「系数 ∈ {0,1}」）整条可以换成一个更自然的说法：

> **计数界**：力**数不出比东西本身更多的条**（且非负）—— `0 ≤ K(u) ≤ 总条数`。

`Unit_of_bound`（界 ⟹ 单位）与 `Bound_of_unit`（在 T5 下单位 ⟹ 界）合证**两条等价**。
所以公理表里只写「界」即可，T7 降为定理。

### 3. 独立性表（HIBS 第 8 步：每条公理都给反模型）

| 公理 | 判定 | 证据 |
|------|------|------|
| T3a 临界非平凡 | **冗余**（可推出） | `nontrivialCrit_free` |
| T3b 非全 | **不可省** | `T3b_needed`：`K = L = 0` 满足其余各条，但张力处处为零 |
| T4′ 反号 | **独立** | `T4'_independent`：`K = \|S∖T\| + \|T∖S\|`、`L = 0` 满足 T5/T6/T7/T3b，却不是力（是个对称距离） |
| T5 自零（两力**各自**为零） | **不可省** | `T5_needed`：否则同一个 τ 可由不同 `(K,L)` 对给出 |
| T5 的 grade 部分 | **冗余** | `diagonal_grade_zero`：T4′ 已蕴含对角差为零 |
| T6 可加 | **独立** | `additivity_needed`：`\|S∖T\|² − \|T∖S\|²` 满足其余各条，却不可加 |

结论：原来那一串里**两条冗余**（T3a、T5 的 grade 部分），**四条有反模型证明独立/不可省**
（T3b、T4′、T5 两力版、T6），**T7 可换成更自然的「计数界」**。压到：

```
T1 直接性  +  T2 二分力
+  T6 计数（可加 且 0 ≤ K, L ≤ 总条数）
+  T4′ 反号  +  T5 自零  +  T3b 非全
```

其中 **T4′ 是把「距离」变成「力」的那一条** —— 唯一一条没有它就有反模型的形状公理。

## 逼出张力：不止一条路，且刚性成立（§9）

除了默认的 T3b 那条，还有别的走法到**同一个** τ：

| 路线 | 怎么逼 | 定理 |
|------|--------|------|
| **T3b 路**（默认） | 只说「存在张力不为零的数对」 | `forced_unique` / `form_up_to_scale'` |
| **核路**（更贴 NODS） | **把要发现的对象直接写进公理**：指定临界流形恰为 `{ \|S∖T\| = \|T∖S\| }`，再给一个归一值 `τ(0,1,0) = 1` | `kernel_forces` |
| **归一 / 极值路** | 形状由 T4′+T3b 逼出后，剩下的只是一个整数刻度 `c`；「计数界」把刻度压到 `±1`。没有界，`c` 可以任意 | `form_up_to_scale'` + `scale_free_without_bound`（`c = 2` 反模型） |
| ~~**乘法性 / Leibniz 路**~~ | 要求 `τ(a, bc) = τ(a,b) + τ(a,c)` —— **得不到**我们的 τ（`a=2, b=3, c=5` 时 `−1 ≠ 0`） | `not_leibniz`（否证） |

结论：**逼出的方式不唯一**（T3b 路与核路都到同一对象），但「乘法性」不是其中一条 —— 它通向另一个对象。

### 刚性（NODS 意义的最小性）

- `two_solutions`：满足公理的张力**恰有两个** —— `τ` 与 `−τ`。
- `forced_grade_swap`：`−τ` 不是「另一个解」，是同一个解**反着读**（`swapProfile`）。
- `swapProfile_involutive` / `swap_nontrivial`：那个「反着读」是对合、且非平凡。

⇒ 解集是两点集，商掉取向是**单点**，取向交换是唯一的非平凡自同构 —— 这就是 `IsMinimal`
（初始对象 + 刚性），与 R→C 的 `(C, i)` / `(C, −i)` 同型。

## 出关：载体抽象（`Nods/Theories/TensionAbstract.lean`）

逼出定理其实**一个字都没用到素数、乘法、ℕ**。它只用一样东西 —— 一对集合的三条计数：

```
profileOf S T := (|S ∩ T|, |S∖T|, |T∖S|)        —— 「原子读数」
```

于是整套东西可以整体出关：

| 项 | 内容 |
|----|------|
| **载体无关逼出定理** | `forced_carrier_agnostic`：`X` 是**任何**类型、`supp : X → Finset A` 是**任何**原子分解 ⇒ 满足公理的张力只能是 `\|supp a ∖ supp b\| − \|supp b ∖ supp a\|`（唯一到取向）。命题里 `X`、`A`、`supp` 全是自由变量 —— 没有 ℕ、没有素数、没有乘法、没有序。 |
| **实例 A（ℕ）** | 原子 = 素数，`supp n` = `n` 的素因子集；`dirTension.grade a b = setTension (supp a) (supp b)`（直读）。 |
| **实例 B（完全不是数）** | 载体直接取「原子集合」本身、`supp = id` ⇒ 张力 = 两个有限集的独有差。**⇒ 张力计数法与数无关，ℕ 只是供应商之一。** |
| **实例 C（ℤ）** | `suppZ z` = `\|z\|` 的素因子集 —— **一行套用，不用重证**。这就是抽象出来的收益。 |
| **直接性（T1）** | `supp_intrinsic`：`p ∈ supp n ↔ p 素 ∧ p ∣ n` —— 原子分解由整除关系定死，**没有任何选择**（唯一分解）。 |

一句话：**TCM 的载体不是「数」，是「原子集合」；数只是通过唯一分解供应原子集合的一种方式。**

所以换载体的代价只剩一件：**找到那个载体自己的内蕴原子分解**。
找到了，公式不变、定理免费、不用重证。

## 扩到实数 / 虚数 / 隐数（`Nods/Theories/TensionCarriers.lean`）

出关之后，「扩到载体 X」只剩一个问题：**X 自己的内蕴原子分解在哪里？** 逐个答，答案都落成了定理：

| 载体 | 原子从哪来 | 判定 |
|------|-----------|------|
| ℕ | 素数（唯一分解） | ✅ `natDecomp` |
| ℤ | `\|z\|` 的素数 | ✅ `intDecomp` |
| ℚ | `num/den` 的素数（分子分母**分开**） | ✅ `ratDecomp` |
| **虚数** | **ℤ[i] 的高斯素数（ℤ[i] 是唯一分解环）** | ✅ `gaussDecomp` |
| **隐数（HIBS）** | `val` 的素数 **＋ 标签本身一条** | ✅ `hiddenDecomp` |
| ℝ（作为域） | —— 域里没有原子 | ❌ 乘法路被定理堵死 |
| ℂ（作为域） | —— 同上 | ❌ 同上 |

**1. 「虚数」的正确落点是 ℤ[i]，不是 ℂ。**
`complex_no_atoms`：ℂ 是**域**，非零元全是单位 ⇒ 没有不可约元 ⇒ 乘法结构里根本没有原子。
而 ℤ[i] 是**唯一分解环**，高斯素数就是它的原子 ⇒ 一行实例（`instance_gaussianint`）。
所以「扩到虚数」= 把载体从 ℂ 换成 ℤ[i]。

**2. 挡住实数的不是「是不是域」—— ℚ 也是域，可它有原子。**
`ratDecomp`：ℚ 的 `num/den` 是典范的，原子就是分子分母的素数（分开算，
否则 `1/2` 与 `2/1` 读数相同）。所以真正的判据是：
**这个载体有没有内蕴的有限分解** —— ℚ 有（靠 ℤ 的算术），ℝ 没有。

**3. ℝ 的缺口是结构性的，不是没找到。**
`field_no_atoms` / `real_no_atoms`：域里非零元都是单位 ⇒ 没有原子。
⇒ 扩到实数，原子分解**不可能**来自 ℝ 自己的乘法结构。只剩两条路：
- 借子结构 ℤ（或 ℚ）—— 那就退化成 `intDecomp` / `ratDecomp`，ℝ 本身没贡献；
- 换**非乘法**读数（连分数 / 序）—— 但连分数给的是**序列**，不是有限集；
  要截断就引入选择，破坏 T1 直接性。

⇒ **「ℝ 上的内蕴有限原子分解」是一个真缺口**：要么承认 ℝ 只能借 ℤ，
要么把抽象从 `Finset` 升级到「序列 / 自由幺半群」—— 那才是扩到实数的下一步。

**4. 隐数（HIBS）有天然原子。**
`Hidden = ⟨val : ℤ, tag ∈ {S, R, iR}⟩`（对应 `~/Downloads/lean/HIBS` 的 `Hidden`）。
原子 = `val` 的素数 **加标签本身一条** —— 标签不是坐标，它是一条**原子** ⇒ `hiddenDecomp`。
机器核对的例子：`hidden_tag_balanced` —— 同值、不同标签的两个隐数，各独有一条（对方的标签），
扳平，张力为零（与数上 `2` 对 `3` 是同一种平衡）。

## 升级：从 `Finset` 到「读数」（序列 / 自由幺半群）（`Nods/Theories/TensionReading.lean`）

上一层的载体接口是 `supp : X → Finset A`（有限集分解）。这一层把它**降为读数**：

```
读数 := (share : 两条共享多少条, size : 一条总共多少条)
```

只要求两件事：`share` 对称、`share ≤ size`。没有集合、没有交并差、没有序、没有乘法。
于是能当载体的东西一下子多了：有限集、**重集（自由交换幺半群）**、**序列（自由幺半群）**。

### 塌缩定理（本层主结果）

```
τ(a,b) = size a − size b            张力 = 两边的「条数」之差
```

**共享项必须约掉** —— 那正是 T5 自零在做的事。剩下的只能是两边的条数差；
「收敛力 / 发散力」只是把条数差拆成两半的记账。

在 ℕ 上它长得很好认（`dirTension_grade_eq_omega_diff`）：

> **张力 = `ω(a) − ω(b)`** —— 两边**不同素数个数**之差。数一数，相减。
> （`60 vs 45`：`3 − 2 = 1`；`2 vs 3`：`1 − 1 = 0`；`30 vs 7`：`3 − 1 = 2`。）
>
> 顺带把早先的说法简化了：**临界流形 = {两边条数相同}**。早先写的
> `{|S∖T| = |T∖S|}` 与它等价，但这个写法直白得多。

### 这条塌缩给出的三个后果

**1. 扩载体的问法变干净了。**

```
扩到 X   ⟺   给 X 找一个内蕴的「条数」 size
```

不必再找集合分解 —— **只要有「条数」**。

**2. 「共同点当收敛力」为什么必然失败（正解）。**
共享项被 T5 强制消去，它根本进不了张力。这不是修一修能救的，是公理组的结构性后果。

**3. 内容不可见（`size_only`）。**
条数相同 ⇒ 张力为零，**不论「是哪些条」差多少**。大小相同、内容完全不同的两条，
在张力上是平衡的。（`2` 与 `3`：互素、毫不相干，但各 1 条 ⇒ 平衡。）

### 实例：序列 / 自由幺半群

`listLCP`：载体 = `List α`（有限序列），`share` = **最长公共前缀长度**（`lcpLen`），`size` = 长度
⇒ 序列成了合法载体，`list_tension_is_length_diff` 说它的张力**就是长度差**。

⚠️ 但要诚实：LCP 属于共享，照样被塌缩约掉 —— **所以 LCP 读数看不见内容，只看长度**。
这不是实现没写好，是塌缩的必然。**任何读数都一样**：内容（是哪些条）永远进不了张力，
进去的只有条数。所以这一层真正的收获不是「序列能算了」，而是：

> **张力只看得见「有几条」，看不见「是哪些条」。**

### 对 ℝ 的意义

判据从「找一个有限集分解」简化成「找一个内蕴的**条数**」。对 ℝ：
- 连分数的**项数**：只对有理性有限（无理数无限）⇒ 拿不到 `size`；
- 「前缀 + 周期」长度：对**二次无理数**有限（Lagrange 定理）⇒ 这一类能进；
- 一般无理数：CF 没有有限表示 ⇒ 仍然进不来。

⇒ 升级**没有**替 ℝ 打开门，但它把门上的锁标清楚了一层：缺的不是「分解」，是**一个内蕴的有限条数**。

### 归因更正：内容不可见是「计数性」的后果，不是 T5

早先本文档把「内容不可见」记成 T5 的后果，**这是错的**。两条承诺分工不同：

| 承诺 | 排除掉的东西 |
|------|-------------|
| **计数性**（力的自变量只有那三个条数） | **「是哪些条」** ← 内容不可见在这里 |
| **T5 自零**（共享不计力：两侧皆零） | **线性共享项**（「共有多 = 收敛」） |

⇒ 想让「**共有多**」进场：放弃 T5。想让「**是哪些条**」进场：必须放弃**计数性**
（也就是放弃「计数法」这个名字本身），让原子带重量。**两者票价不同。**

## 塌缩的哲学含义：这个名字把整个理论写完了

塌缩定理说「张力 = 条数差」。这看着太薄 —— 但它薄得有道理：**它不是缺陷，是四条承诺的精确外延。**

| 承诺 | 语义 | 排除了什么 |
|------|------|-----------|
| **计数**（自变量只有三个条数） | 只看「有几条」 | 「是哪些条」← 内容不可见 |
| **线性**（可加） | 力的可加性 | 耦合项（如 `share × (ownA − ownB)`） |
| **是力不是距离**（T4′ 反号） | 有方向 | 一切对称量（共有数、对称差、Jaccard） |
| **共享不计力**（T5：两侧皆零） | 共有条不产生力 | 线性共享项（「共有多 = 收敛」） |

四条都排掉，能剩下的只有一个东西：**条数差**。所以

> `τ = 条数差` 不是「太薄的结果」，而是这四条承诺的**精确外延 —— 没有一丝余量**。

**读法一（作为「极简计数法」：好消息）**：你要的就是极简。塌缩定理恰好证明
**这个方法已经不能再简了** —— 四条承诺 ⟹ 一个输出，且唯一。极简到手，而且可证。

**读法二（作为「新空间」：坏消息，但它支持你最初的直觉）**：`τ = ω(a) − ω(b)`。
`ω` 是 1934 年的（Hardy–Ramanujan），它的分布是 1940 年的（Erdős–Kác）——
**条数差不是新空间，新的只是「它是被逼出来的」这件事。**

但你说「数字本身有临界现象」，**这个直觉是对的**：那个临界现象**正是 ω 的分布**
（Erdős–Kác 正态律：`ω(n) ≈ log log n`，涨落尺度 `√(log log n)`）。数字确实在临界，
而这点临界性**完整地住在条数里** —— 这正是为什么被逼出来的张力恰好是条数差。

那么 ζ 的零点、`Re = 1/2` 在哪？**不在条数里。** 那是 Dirichlet 级数的分析结构
（函数方程、解析延拓），不是计数统计。**RH 不在计数里。**

**读法三（最要紧）：这个理论是关于「什么算一条」的，不是关于力的。**

> **选原子（语义全在这里） + 数条数（力在这里被逼死）**

一旦原子分解决定，力就没有任何自由度了。所以 TCM 不是「关于力的理论」，而是
**把载体翻译成力的规范器**：**全部的艺术、全部的自由，都在「什么算一条」上**。
这也让前面两件看似无关的难事显出同一个形状 —— 「ℝ 进不来」是 ℝ 没有内蕴的**有限条数**；
「内容进不来」是读数只给**条数**、不给「是哪些条」。**两者都不是公式的问题，都卡在原子分解那一侧。**

### 「没被观测过的空间」在哪：三个门，各有票价

| 放弃哪一条 | 得到什么 | 票价 |
|-----------|---------|------|
| **计数**（让原子带重量） | 加权版 `τ_w = Σ_{p∈A∖B} w(p) − Σ_{p∈B∖A} w(p)`；`w ≡ 1` 退回条数差 | 得回答「哪个 `w` 被逼出来」；`w = log p` 给出 `log(a/b)`（又是旧的） |
| **线性** | 允许耦合，如 `share × (ownA − ownB)`（共有越多，差一点越刺眼） | 力不再可加，记账性质丢掉 |
| **共享不计力**（T5） | 回到最初的两力图景：收敛力 = 共有条数、发散力 = 不对称 | 数与自己有张力（`K(a,a) = |A|`），「力」变成「亲和度」 |
| **是力**（T4′） | 得到**距离**（对称差 / Jaccard） | `metric_not_nontrivial` 已证：这条路到不了非平凡临界流形 |

### 缺的件是「对合 + 1/2」—— 已做成定理（`Nods/Theories/TensionDuality.lean`）

`Re = 1/2` 的形状是「**一条自己与自己配对的线**」—— 函数方程 `s ↦ 1−s` 的**固定集**。
用张力的话说：`τ(s, 1−s)` 的两个自变量在 `s = 1/2` 处**合体**，正是「自零」发生的地方。

而当前公理组里**没有对合**：ℕ 上 `τ(a,a) = 0` 是平凡的（自己对自己），**没有「另一个自己」**。
所以计数公理体系**结构上**造不出中心线 —— 不是没做够，是缺一个件。这个件已经补上并证了：

| 定理 | 内容 |
|------|------|

## 扩到 ℝ 与 ℂ：代数数的「次数读数」（`Nods/Theories/TensionAlgebraic.lean`）

前一层的结论是「ℝ / ℂ 作为**域**没有乘法原子 ⇒ 乘法路堵死」。本层换一条路：
**不数因子，数共轭。**

对代数数 `x`（`IsIntegral ℚ x`），极小多项式 `minpoly ℚ x` 是本征的（monic、不可约），
它的次数 `[ℚ(x) : ℚ]` 就是 `x` 的**共轭个数** —— 一个内蕴的有限数：

```
条数 size(x) := deg (minpoly ℚ x)       （= 共轭个数 = 域扩张次数）
共享 share(x,y) := 极小多项式相同时取全部，否则 0
```

⇒ 按塌缩定理（用的是**优化后的四条表**）：

```
τ(x, y) = deg x − deg y                 张力 = 次数差
```

**一次定义，两个载体**：`algReading` 只要求 `L` 是 ℚ 的域扩张，所以

- **`algReadingR`** —— ℝ 的代数部分。这是「扩到 ℝ」的正面回答。
- **`algReadingC`** —— ℂ 的代数部分。注意它与 ℤ[i] 那次是**同一载体的另一个读数**
  （ℤ[i] 数高斯素数，这里数共轭）⟹ **同一载体可以有多个读数，读数不同、张力不同**；
  但每个读数内部，张力仍被公理逼死。

| 定理 | 内容 |
|------|------|
| `alg_tension_is_degree_diff` | 代数数的张力 = 次数差（或反号），**不需要 T5** |
| `alg_tension_zero_of_same_size` | 条数相同 ⟹ 张力为零 |
| `natDegree_minpoly_rat_real` | 有理数 `a` 的极小多项式是 `X − a` ⟹ **条数 = 1**（ℝ 版，已机器核对） |
| `natDegree_minpoly_rat_complex` | 同上（ℂ 版） |
| `size_of_minpoly_X_pow_sub_C` | 极小多项式形如 `Xⁿ − c` ⟹ 条数 = `n`（`√2` 与 `i` 都是这一型，条数 2） |

**诚实边界（三条）**

1. **超越数仍进不来**：没有有限极小多项式 ⟹ 没有有限条数。进的是 ℝ/ℂ 的**代数部分**。
   ⇒ **早先「ℝ 的缺口是结构性的」要修正**：不是「ℝ 完全进不来」，而是
   **ℝ 的非代数部分进不来** —— 代数部分有一条内蕴的路（次数），而这条路**不是乘法**。
2. **次数读数很粗**：有理数全是 1 条 ⟹ **有理数之间张力恒为零**；共轭的数也全共享。
   这是**读数的分辨率**问题，不是公理的问题。
3. **`share` 取「极小多项式相同」而非「共同因子的次数」**：更细的 gcd 版本需要多项式 gcd
   的归一化引理（`gcd m m = m`）；而按塌缩定理，**共享项对张力毫无影响**，故不必要。
