## 一句话定义

**振数坐标系（Vibration Coordinates）** 是一套以「振动」为模式的数学坐标系 —— 载体上的每个
对象被赋予一个**振数**（振动周期 = 轨道长度），对象之间的相互作用（张力）被公理**逼成**振数差。
它既不是笛卡尔坐标系（位置投影），也不是虚数坐标系（旋转分解），而是第三类：**周期 / 相位分解**。

## 为什么：弦理论的不对称（HBS 第 1–2 步）

弦理论把「弦」当载体、「弦的振动」当属性。leo 的滞涩点：**同一振动不依赖载体** ——
sin 函数振动时并没有一根弦；点可以振动（自旋）、面可以振动（膜）、数也可以振动（对合）。

不对称在于：标准理论**处处用**振动模式做事（简正坐标、傅里叶展开、弦的谱），
却从不把「振动」本身当作一个可逼出的数学对象来公理化 —— **振动是「被使用的」，不是「被定义的」**。

## 真空诊断（HBS 第 4 步）

经典力学有「简正坐标」（normal coordinates）= 以振动模式为轴的坐标系，但它是**选出来的**（对角化一个
给定的 Hamiltonian），从未被问过：振动坐标能否从计数公理里**被迫出来**，且与载体无关？

- 现有数学：振动总是「某物的振动」—— 依赖一个被振动的东西
- 真空：**振动本身作为第一性本体**的坐标系规范（原点 / 坐标 / 可加性 / 动力学）

## 构造：振动 → 读数 → 塌缩（HBS 第 5–6 步）

### 1. 振动结构（载体无关）

```lean
structure Vibration (X) where
  step   : X → X        -- 振动一步（相位推进）
  period : X → ℕ        -- 振数：轨道长度
  step_period     : step^[period x] x = x      -- 周期律
  period_invariant : period (step^k x) = period x  -- 周期是轨道不变量
```

载体 X 可以是**任何类型**：点（`Fin 2`）、线（`Fin 3` 环）、面（`Fin 2 × Fin 3`）、数（`ℚ`）。
「一切皆可振」不是口号，是结构签名 —— 承接 `forced_carrier_agnostic` 的载体无关精神。

### 2. 振数读数（接入已有公理体系）

```lean

  size  x := period x                        -- 振数
```

`AtomicReading` 是 TCM 读数升级后的接口（`TensionReading.lean`），只要 `share` 对称 / `share ≤ size` /
自共享三条性质。**振数从这一刻起进入已有的公理体系，不再需要新公理。**

### 3. 塌缩定理（主结果，被迫）

```lean

  τ.grade (toProfile a b) = period a − period b   ∨   反号
```

满足 TCM 公理（T6 可加 + T7 单位 + T4′ 反号 + T3b 非全，**无需 T5**）的振动张力，

而是任何满足计数公理的振动张力都只能是振数差 —— 与 ℕ 素因子、序列长度、代数数次数同型。

## 动力学：振动自带时间

- **时间 = 轨道脚步数**（`phase k x := step^k x`）
- **不动点 = 不振**（`period = 1 ⟹ step x = x`）
- **临界线 = 不振集**（不动点处张力为零：`fixed_point_balanced`）
- **最小振动 = 对合**（周期 2 的往返，`involutionVibration`）—— 对合层（`TensionDuality.lean`)
  全部结论直接复用：`Re = 1/2` 就是「`x ↦ 1 − x`」这个对合的不动点 = 数振动里不振的那个数

## 实例

| 载体 | 振动 | 振数 | 临界（不振） |
|------|------|------|--------------|
| 点 `Fin 2` | `0 ↔ 1` 交换 | 2 | 无不动点 |
| 线 `Fin 3` | `0 → 1 → 2 → 0` 循环 | 3 | 无不动点 |
| 面 `Fin 2 × Fin 3` | 两个方向各自振 | 2×3 = 6 | 无不动点 |
| 数 `ℚ` | `x ↦ 1 − x` 反转 | 1 或 2 | **`1/2`**（= `Re 1/2` 的形状） |

最后一个实例最有意思：**数本身在振动**，而那个不振的数正是 `1/2` ——
与对合层 `revQ_one_fix_iff_half` 完全吻合（`1 − x = x ⟺ x = 1/2`）。

## 与弦理论的关系（诚实边界）

- **数学层**：我们证明的是 —— 若振动张力满足计数公理，它必然是振数差；载体可以是点/线/面/数。
  这支持「振动优先于弦」的直觉：**弦只是众多载体之一，不是必需的**。
- **不声称**：「弦不存在」或「这是弦论的替代」。弦论里的频率/质量谱是动力学内容（哈密顿量对角化），
  我们的公理体系管不到那些；给的是**一切振动共享的计数骨架**。
- **连接点**：弦的振动模式展开（傅里叶模式）与我们的「振数 = 周期」同属**周期分解**这一族；
  我们的版本不预设载体是线。
